# 0.4.0 validation

Verified 2026-11-13 with Node 24 and official DSH 0.2.2-rc.2 Web on macOS.

## Automated and independent review

- 289 assertions passed while running the actual client bundle against the official host contract and mocked browser lifecycle/storage/media.
- New tests were observed failing before implementation: protection floors, profile switching/persistence/failed writes/reset/corrupt data, and still-video pause priority.
- Independent read-only review found no blocking defects. The reported Advanced settings wording mismatch was corrected.
- Real-host testing showed that 94% dialog opacity still revealed underlying text. A regression test first failed, then passed with opaque layer-2/overlay surfaces; other protected content/code/menu surfaces retain a 94% floor.

## Real packed-package verification

The package was installed from its npm tarball into an isolated Web profile, with no account or model credentials. The installed client bytes matched the release source.

- Native collapsed entry below Appearance, official controls and advanced disclosure work.
- Light Clear at 65% transparency and dark Frost at 22% persist separately after restart.
- Switching the host theme retains an unsaved video draft. Saving commits the media.
- Dark Still frame pauses an existing video; returning to light Motion resumes playback.
- After a reload in dark Still frame, the background video has `paused=true`, `readyState=4`, `videoWidth=640`, `currentTime=0`; the decoded first frame is visible in the preview and background.
- Final protected light/dark settings dialogs no longer show underlying text.
- Four 1280×720 screenshots in `assets/screenshots/v0.4.0/` capture the installed package and original local demonstration media.

## Official API evidence and limits

`ThemeRuntime.getTheme().active.colorScheme` is the documented resolved palette, also used for custom themes. Changes arrive via `theme/change`; token writes emit the same event and the plugin guards against re-entry. The official Modal CSS consumes `--dsw-alias-bg-layer-2`.

System/custom palette events and hidden/reduced-motion behavior have automated coverage; actual OS theme transitions, Windows/Linux codecs and CPU/GPU/power consumption were not measured in this release. Still frame keeps a loaded video element, not a decoder-free exported poster. Storefront screenshot refresh depends on its next index build.
